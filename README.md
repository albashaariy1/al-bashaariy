# AL BASHAARIY

Flutter starter app for the AL BASHAARIY bilingual Arabic library.

## Poem sharing
The Share button now opens the device's native sharing sheet with a polished,
copy-friendly format containing:
- AL BASHAARIY branding
- Poem title
- Arabic author name
- English author name
- Full Arabic poem
- English translation
- AL BASHAARIY library footer

The share subject is also set to:
`AL BASHAARIY | مَرَرْتُ إِلَى الْعُلَا`

## Other working poem controls
- Favorite
- Download
- Real bundled audio playback
- Pause/resume
- Audio progress slider

## Run
1. Install Flutter.
2. Open this folder in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Run `flutter run`.
